# 🍔🧪 Тестовые сценарии сервиса  Stellar Burgers

## 📌 Описание

Набор[Diplom_1](..%2FDiplom_1) сценариев для проверки основных пользовательских функций. 

---

* Реализована поддержка прогонов в популярных браузерах:

  * 🌐 **Google Chrome**
  * 🦊 **Mozilla Firefox**
* Это позволяет проверить стабильность продукта в наиболее популярных средах.
## 🔹 Проверка основной функциональности



* переход по клику на **«Конструктор»**;
* переход по клику на раздел **«Лента заказов»**;
* при клике на ингредиент появляется всплывающее окно с деталями;
* всплывающее окно закрывается кликом по крестику;
* при добавлении ингредиента в заказ счётчик этого ингредиента увеличивается.

---

## 🔹 Раздел «Лента заказов»



* при создании нового заказа счётчик **«Выполнено за всё время»** увеличивается;
* при создании нового заказа счётчик **«Выполнено за сегодня»** увеличивается;
* после оформления заказа его номер появляется в разделе **«В работе»**.

---

💡 Эти проверки позволяют убедиться в корректной работе ключевого функционала приложения.

## 🚀 Инструкция по запуску тестов

### 1️⃣ Установка зависимостей

Убедитесь, что находитесь в корне проекта, и выполните:

```bash
pip install -r requirements.txt
```

---

### 2️⃣ Запуск всех тестов с генерацией отчёта Allure

```bash
pytest tests --alluredir=allure-results
```

---

### 3️⃣ Просмотр отчёта в HTML-формате

```bash
allure serve allure-results
```
